# Vibe Virtue — Design Brief

## Brand
- **Name:** Vibe Virtue (vibevirtue.com); entity Vibe Virtue Enterprise LLC. A modern, credible consulting brand.
- **Voice:** professional, outcome-focused, approachable.

## Color / type
- Styled with **Tailwind CSS 4** (theme in `src/styles/global.css` / Tailwind config). Exact brand hex values and font families are defined there — record precise values when confirmed (treat as an open item; not captured in the data files reviewed).

## Component style
- Reusable primitives: `Container`, `Section`, `SectionHeading`, `Card`, `Badge`, `Button`, `ButtonLink`, `PricingCard`, with `buttonStyles.ts`. Clean sectioned landing-page layout with pricing cards.

## Imagery / illustration
- `lucide-react` icons for services/outcomes; a replaceable portrait placeholder in the About section; favicon `public/favicon.svg`. Light on photography.

## Motion rules
- Subtle, professional transitions; avoid heavy animation that undercuts credibility.

## Accessibility targets
- Contrast on the brand palette; visible focus; 44px targets; semantic headings per section.

## Responsive breakpoints
- Tailwind defaults (sm/md/lg/xl); mobile-first.

## Reference sites
- Modern consulting/agency landing pages with clear service + pricing sections.

## What to avoid
- Overclaiming; clutter; anything that reads as a generic template.
