# Vibe Virtue — built site for Hostinger

This branch contains the production build output (the contents of `dist/`).

- Upload everything here (including the hidden `.htaccess`) into `public_html`, or
- Download `vibevirtue_public_html_upload.zip` and extract it into `public_html`, or
- Point Hostinger "Deploy from Git" at this branch.

Built from `cursor/phase-11-deployment-prep-add6`. Rebuild with `npm run build` on that branch (or `main` once phases 7-11 are merged).
